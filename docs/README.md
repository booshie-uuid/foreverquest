# ForeverQuest Documentation

These documents describe how the ForeverQuest engine is put together and how to extend it. They are for developers who change the code. The [project README](../README.md) covers running the game, the controls and the art style.

| Document | Covers |
|---|---|
| [Architecture](architecture.md) | The layers and modules, the frame loop, state and events, and the units and coordinate systems |
| [Assets and the Bake](assets.md) | The boundary between authoring and play, the bake, the lock file, id migrations and how the game loads assets |
| [Character Kit](character-kit.md) | How an appearance becomes block characters, the texture sheet and painters, animation, and how to add hair, items and races |
| [Workbench](workbench.md) | The model viewer and the capture command |
| [World](world.md) | Tile terrain, world textures, the prop kit, collision, lighting, and how to add props and tile types |

Read the architecture document first. The character kit and world documents each stand alone after that.
